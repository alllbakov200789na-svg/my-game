# Отчёт по этапам

Состояние: файловая alpha, 24 октября 2026. Все восемь этапов получили реализацию в исходниках; игровая и визуальная приёмка в Studio не выполнена. Отчёт не объявляет исходное задание полностью завершённым.

## 1. Инспекция и база

**Создано:** новая структура, настройки, оригинальное лобби, основной автомат раунда и серверный bootstrap. До изменений папка содержала только пустые outputs/work. Подключённых Studio не было. Исходное задание и запись исходного состояния сохранены в work/backup; резервировать существующий игровой проект было нечего.

**Файлы:** src/Shared/*, src/Server/Bootstrap.server.lua, src/Server/Services/RoundService.lua, tools/build.mjs, default.project.json, assets/Lobby.rbxmx, JujutsuCursedSurvival.rbxlx.

**Подтверждено:** компиляция и XML, unit переходов состояний. **Не подтверждено:** одинаковое состояние двух клиентов, настоящий spawn и загрузка R15. **Найденные ошибки:** запрещённые/повторные переходы теперь явно проверяются. **Осталось / владелец:** открыть файл и пройти T01/T02.

## 2. Игровая логика

**Создано:** пять правил победы, минимальные составы, сбалансированные команды Clash, рандом с RolePity, скрытый носитель, результаты, выдача наград и возврат в лобби. Carrier хранится только на сервере. Выход носителя обработан через повторный выбор до превращения и обычный исход после него.

**Файлы:** RoleService.lua, ModeService.lua, RoundService.lua, RewardService.lua, RoundDefinitions.lua, CharacterDefinitions.lua.

**Подтверждено:** 15 назначений в каждом режиме, выбор только допустимых режимов для 0–15 игроков, веса/сброс pity, ветви побед/поражений/ничьих. **Найденные ошибки:** при превращении теперь сохраняется статистика раунда. **Осталось / владелец:** реально завершить все режимы обоими исходами, пройти отключения и overtime.

## 3. Боевая система

**Создано:** 26 действий, модульные параметры, melee/projectile/AoE, защита, лечение, stun, притяжение/отталкивание, рывки, телепорт, summon, ловушка, domains, энергия/выносливость, server cooldown, server hit/LOS, роль/команда и ограничения Remotes. Есть катана или кулаки, смерть и spectator.

**Файлы:** AbilityDefinitions.lua, CharacterService.lua, AbilityService.lua, CombatService.lua, DamageService.lua, AntiExploitService.lua; клиентские InputController, CombatController, SpectatorController.

**Подтверждено:** компиляция, 1000 пар техник, unit урона, cooldown, ultimate, ownership/NaN, защита союзников и двойной смертельный вызов. **Исправлено:** параметр Teleport, нулевой horizontal aim, перенос статистики, сброс motion-record, прекращение summon после смены автора. **Осталось / владелец:** анимационные/физические плейтесты, wall hits, меткость, баланс, скорость и лаг.

## 4. Мир

**Создано:** SHIBUYA CITY (812 instances), SORCERER ACADEMY (530), CURSED DISTRICT (621); лобби 170. На каждой карте 16 spawn, 3 печати, энергия, препятствия, безопасное основание. Построены фасады, интерьерные маршруты, лестницы/крыши, арена, сад, мосты, руины и энергетические трещины. Разрушение трёх уровней влияет на коллизию. NPC: Weak/Fast/Elite, масштабируемый босс и теневая собака; лимит 18, pathfinding budget.

**Файлы:** tools/build.mjs, assets/Maps/*, assets/Lobby.rbxmx, MapService.lua, DestructionService.lua, NPCService.lua.

**Подтверждено:** XML-структура всех карт, числа spawn/задач/разрушаемых частей. **Исправлено:** разные HP уровней разрушения, отдельная форма собаки, метка Y для печатей. **Осталось / владелец:** визуальная приёмка, реальная навигация NPC, доступность печатей, отсутствие застреваний/провалов, восстановление карты.

## 5. Анимации и графика

**Создано:** стилизованные R15, волосы/повязка/метки/воротник, team outlines, процедурные позы, ParticleEmitter/Beam/Trail, кольца, локальные обломки, снаряды, domains, свет/цветокоррекция, интро-камера, ограниченная тряска/FOV, настройки доступности. Синтезированы 5 WAV.

**Файлы:** CharacterService.lua, CombatController.lua, CameraController.lua, VFXController.lua, SoundController.lua, tools/audio.mjs, assets/Audio/*.

**Подтверждено:** синтаксис; файлы звука физически созданы. **Частично:** профессиональные клипы, сложные кинематографические сцены, детальный арт-пасс и превью моделей отсутствуют. Аудио не звучит до загрузки ID владельцем. Текущие позы и эффекты процедурные, их качество не просмотрено в движке. **Осталось / владелец:** загрузить WAV, при желании создать/опубликовать анимации, проверить FX/камеру на устройстве. Никакие AnimationId не выдумывались.

## 6. Интерфейс

**Создано:** здоровье/энергия/выносливость, таймер и цель, cooldown/ultimate, меню, монеты/уровень, магазин, цветовое превью косметики, коллекция, статистика/счёт команд, задания/день, настройки, результаты, роль, обучение, приглашения и spectator. Touch-кнопки, безопасные inset и resize.

**Файлы:** UIController.lua, InputController.lua, ClientBootstrap.client.lua, SpectatorController.lua.

**Подтверждено:** синтаксис, API ScreenInsets сверена по первичной документации. **Частично:** превью косметики представляет цветовую карточку, не 3D-персонажа; портретные экраны могут требовать доработки. Ни один UI не проверен в Studio/эмуляторе. **Осталось / владелец:** пройти каждую кнопку, выполнить T15/T16 и проверить читаемость/пересечения с джойстиком и прыжком.

## 7. Экономика

**Создано:** активные награды и защита от простого AFK-фарма, XP/уровни, бесплатная Azure на уровне 5, косметика, фиксированный сундук, ежедневные/недельные задания, дневной бонус, pass ownership, loadouts, безопасный единый ProcessReceipt. Сохранение с lease/autosave/retry; закрытие сессии при неопределённой записи. Studio работает в памяти.

**Файлы:** PlayerDataService.lua, MonetizationService.lua, QuestService.lua, RewardService.lua, Config.lua, UIController.lua.

**Подтверждено:** simulated receipt duplicate/rejoin, ambiguous-commit retry, чужой lease, отказ сохранения, запрет Studio receipts. **Частично:** все реальные product/pass ID NOT_CONFIGURED; настоящая монетизация/сохранение не запущены. **Осталось / владелец:** настроить реальные ID только после закрытой приёмки, проверить покупку/выход/вход. Не включать продажи раньше.

**Файлы:** tests/core.spec.lua, tests/boundaries.generated.lua, tools/test-bundle.mjs, tools/verify.ps1, docs/QA.md, docs/AUTOMATED-RESULTS.txt.
